# Daily Affirmations

A calm, nature-themed webpage that gives you a positive affirmation each time
you press a button. Python standard library only, so there is nothing to install.

## Run it

    python3 server.py

Your browser opens at http://localhost:8000. Press **Ctrl+C** in the terminal to stop.
Options: `--port 9000`, `--no-browser`, `--data-dir some/folder`.

## What it does

- **Give me an affirmation** shows a random affirmation, never the same one twice in a row.
- **Stars (1-5)** rate the affirmation on screen. The average is shown under the stars.
- **Write your own** adds your affirmation to `affirmations.txt`, so it joins the cycle.
- **Calming music** is generated by Python (`calm_music.wav`) and loops. Press play
  (browsers do not allow sound to start on its own).

## Files

| File | Purpose |
|---|---|
| `server.py` | starts the web server; decides what each URL returns |
| `affirmations.py` | reads and writes `affirmations.txt` and `ratings.json` |
| `pages.py` | builds the HTML and CSS for the page |
| `music.py` | builds the ambient music from sine waves |
| `tests/` | unit tests for every function |

Created when you first run it: `affirmations.txt` (one affirmation per line, so you
can edit it by hand too), `ratings.json`, `calm_music.wav`.

## Tests
